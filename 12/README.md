# Chapter 12 — Web Scraping & HTML Parsing

Covers DOM navigation, CSS selectors, XPath, data extraction, and a complete scraping pipeline that outputs JSON and CSV.

## Technologies Used

- **requests** — HTTP client for fetching web pages
- **BeautifulSoup** (bs4) — HTML tree parsing, CSS selector search, and text extraction
- **lxml** — fast XPath-based parsing and tree navigation
