# Chapter 13 — NLP with Hugging Face Transformers

Covers sentiment analysis, tokenisation, multiple NLP tasks (NER, summarisation, translation, QA), fine-tuning, and a complete Gradio-powered NLP app.

## Technologies Used

- **Hugging Face Transformers** — pre-trained NLP pipelines (sentiment, NER, summarisation, translation, QA)
- **PyTorch** — deep learning backend for all Transformers models
- **Gradio** — interactive ML demo UIs
- **Hugging Face datasets** — dataset loading and fine-tuning workflows
- **scikit-learn** — evaluation metrics (`classification_report`, `accuracy_score`)
- **pandas** — data handling and batch processing
- **numpy** — numerical operations
